================================================================================
                            MAJOR FINDINGS
================================================================================

1. STRONG EVIDENCE UTILIZATION ✓
   When required facts are in top-5, EcoRAG retrieves and uses them 91% of
   the time. Answers are correct 100% of the time (14/14 sufficient questions).

2. CRITICAL CALIBRATION FAILURE ✗✗
   When evidence is absent or incomplete, the model should abstain.
   It does so ONLY 44% of the time (4/9). The other 5 times it answers anyway,
   usually by substituting related entities or generalizing beyond scope.
   THIS IS THE PRIMARY FAILURE MODE.

3. CITATION CORRECTNESS IS BROKEN ✗✗
   24% of cited claims (20/85) incorrectly point to sources.
   This is concentrated in dependent-source questions (78% error rate).
   The system confuses which document supports which claim in multi-source tasks.

4. RETRIEVAL IS SECONDARY
   18% of required units aren't retrieved (manageable).
   The bigger problem: even when nothing is retrieved, the model answers.

5. GENERATION WORKS FINE
   Only 5% of failures are due to retrieved units not being used.
   When evidence is available, the model reads and uses it correctly.

6. PARTIAL EVIDENCE HANDLING IS WORST
   Only 1/4 partial-evidence questions handled correctly.
   System treats partial evidence like no evidence (over-answers).

7. DEPENDENT-SOURCE QUESTIONS ARE CITATION DISASTERS
   Single-chunk questions: 0% citation error ✓
   Dependent-source questions: 78% citation error ✗
   Clear pattern: multi-source reasoning breaks citation binding.

================================================================================
                          RECOMMENDATIONS
================================================================================

FOR EXPERIMENT D (Improvements):

1. CALIBRATION-AWARE PROMPT
   • Add confidence threshold: "If you don't find the answer in the given
     passages, say I don't know."
   • Or use entropy-based abstention: "If confidence < X, abstain."

2. CITATION BINDING LAYER
   • Track source→claim mappings explicitly
   • Validate each claim against its cited passage before output
   • Penalize misattributions

3. MULTI-SOURCE REASONING
   • Special handling for dependent-source questions
   • Explicit source tracking across documents
   • Contrastive learning on correct vs incorrect bindings

4. IMPROVED GOLD LABELS
   • Second manual reviewer to validate the 85 citation decisions
   • Continuous (Likert) sufficiency labels instead of binary
   • Tighter rubric for "unsupported" classification

5. LARGER EVALUATION SET
   • Expand beyond 27 questions
   • Stratified sampling across document types
   • Multiple independent reviewers
