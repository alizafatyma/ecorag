EcoRAG – Experiment B: model size (Qwen2.5-1.5B -> Qwen2.5-3B), v3 prompt held fixed

Held constant (verified): the 6 questions; top-5 retrieved chunks (ids, texts and the full v3 prompt identical to
Experiment A for all 6 questions); evidence format; v3 prompt; greedy decoding, bf16 on CPU, max 400 new tokens;
ecorag_ask.py and ecorag_verify.py (file fingerprints unchanged before/after the run); scoring method.
Changed: only the model. Hardware: Intel Core Ultra 7 155H CPU, 15.5 GB RAM (Chrome closed, ~6.9 GB free), on AC power.

WHAT IS MEASURED: citation correctness ("does the cited passage support the claim?"), per claim, by the same
deterministic verifier. NOT measured here: evidence sufficiency ("does the retrieved evidence collectively justify
the conclusion?") - that is Experiment C. "Supported" = key numbers + >=60% content words in the cited source
= POTENTIALLY supported (word-level), confirmed by a manual check below.

IMPROVED with 3B
- Misattribution rate roughly halved (50% -> 19%; 60% -> 31% excluding Q3).
- Q6 abstention restored ("The provided sources do not contain enough information about electric cars sold
  in India in 2023.") - although the line carries an unnecessary [5].
- Key facts 2/5 -> 5/5: Q5 thresholds back (400-50 / 125-40 kg CO2-eq/t, correctly cited [3][4]); Q4 now gives the
  actual "how" (tripling of concessional funds [5], policy/regulation and de-risking instruments).
- Q2 date/scope error fixed: "by February 2026" and "12 per cent in 2025", exactly as in the sources.

PERSISTED
- Q1 misattributed in every run (v1-v3-3B): the 3B sentence is copied verbatim from [5] but cited [4].
- Q2 misattributed in both v3 runs: 5,000 and 12% are only in [1][3], both models cite [2].
- Content from source [5] attributed to [1] in Q4 (2 lines).

NEW REGRESSIONS (3B)
- Format: Q3 ignored the 8-line limit (19 lines), near-duplicate lines, truncated last line (uncited).
- Spurious citation on the abstention line (Q6 "[5]").

Runtime (s): 1.5B v3 280/394/348/372/413/326; 3B 344/308/378/484/471/414. (Not a fair speed comparison:
the 1.5B runs had ~2 GB free RAM and heavy paging; the 3B run had ~6.9 GB free.)

CONCLUSION
Model size helps substantially on this test set: fewer misattributions, correct abstention, complete key facts and
no date distortion. It does not eliminate misattribution (Q1 and Q2 fail for both models, ~1 in 5 cited claims
still wrong) and introduces verbosity/format violations. Small test set (6 questions): indicative, not precise.
